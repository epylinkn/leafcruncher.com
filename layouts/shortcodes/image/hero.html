{{/* @class: figure class @link: href @src: image src — a page-bundle resource, or any path @alt: image alt @caption: figure caption @title: figure caption @credit: photo credit When src resolves to a page resource, a srcset is generated so a phone downloads a phone-sized file instead of the full-width one. Sources already narrower than a breakpoint are not upscaled — there is no detail to invent, and several works here ship at under 1200px wide. Anything that doesn't resolve (a /static path, a missing file) falls back to a plain img, so a broken lookup degrades instead of failing the build. */}} {{- $src := .Get "src" }} {{- $res := "" }} {{- with .Page.Resources.GetMatch $src }}{{ $res = . }}{{ end }} {{- $alt := cond (ne (.Get "alt") "") (.Get "alt") (.Get "caption") }}
